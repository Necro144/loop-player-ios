## What's new in 1.0.1

- Fixed: choosing a folder and tapping **Open** did nothing. The folder is now added and the songs show up right away.
- The folder picker now picks the folder you are in when you tap Open (one folder at a time; add more in Settings > Folders).
- New automatic test: on an iOS 16.4 simulator it taps Choose a Folder, opens a "Suno Songs" folder in the Files picker, taps Open, plays a song, then closes and reopens the app to check the folder is remembered.

## Install

Download `LoopPlayer.ipa` below and install it over the old one with TrollStore, AltStore or Sideloadly. It is unsigned.
