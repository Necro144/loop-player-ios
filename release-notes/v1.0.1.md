## What's new in 1.0.1

- Fixed: choosing a folder and tapping **Open** could do nothing. The picker now stays connected until it reports the folder, and any problem is shown on screen instead of being dropped silently.
- New: Settings > Folder Log shows what happened when a folder was picked and scanned (copy button included), so a problem on the phone can be read off the screen.
- The folder picker now picks the folder you are in when you tap Open (one folder at a time; add more in Settings > Folders).
- New automatic test: on an iOS 16.4 simulator it taps Choose a Folder, opens a "Suno Songs" folder in the Files picker (one inside the app, one directly in On My iPhone like an iCloud folder), taps Open, plays a song, then closes and reopens the app to check the folder is remembered.
