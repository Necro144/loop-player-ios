## What's new in 1.0.2

Choosing a folder and tapping **Open** could still do nothing, as if Open was never tapped. The most likely cause is iOS refusing to hand the folder to an app installed without an Apple signature (TrollStore). This version no longer depends on that picker:

- **New: Browse iPhone Folders** (TrollStore `.tipa` only). The app opens iCloud Drive and On My iPhone itself, without the system picker. Open your folder and tap **Use This Folder**. Subfolders are included.
- **New: Use the Loop Player folder.** Works on every install. Put songs in Files > On My iPhone > Loop Player and they show up, no picker needed.
- **New: `LoopPlayer.tipa`** for TrollStore, next to the IPA.
- Songs show up and can be played while the library is still being read, instead of only at the end.
- iCloud files that are not on the phone yet are no longer downloaded during the scan. They download when you play them.
- One slow or broken file can no longer hold up the scan (each file gets 20 seconds at most).
- Folder Log now also writes a line if the app crashes or stops responding, so the last step is visible afterwards.

## Install

- **TrollStore:** download `LoopPlayer.tipa` and open it with TrollStore (install over the old one).
- **AltStore / Sideloadly:** use `LoopPlayer.ipa`. The system picker works there because the app gets signed with your Apple ID.
