## What's new in 1.2.2

**Fixed: Suno sign-in buttons did nothing**
- In 1.2.1, Continue with Google, Apple, Discord, Facebook and Microsoft didn't respond. Those buttons open a second window, and the app refused it.
- That window now opens inside the app, on top of Suno's page, with a "‹ Back to Suno" bar. When you finish signing in there, it closes by itself and the app shows "Signed in as …".
- The sign-in screen no longer closes when you swipe down; use Close.
- Each button was tapped in an automatic iPhone test before this release, and each one opened its sign-in page.
- If signing in still fails, Settings > Folder Log lists every page the sign-in opened and any error it showed.
